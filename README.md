# Wallet Portfolio Dashboard

A simple multi-chain wallet portfolio dashboard for EVM addresses.

Enter a public wallet address and inspect native balances and ERC-20 token holdings across supported networks.

## 🌐 Live Demo

https://nikatose.github.io/wallet-portfolio-dashboard/

## ✨ Features

- Ethereum support
- Base support
- Arbitrum One support
- Optimism support
- Polygon support
- Native token balances
- ERC-20 token detection
- Token metadata
- Token icons
- USD price data when available
- Portfolio allocation
- Token sorting
- Explorer links
- Address copy button
- Responsive design
- No wallet connection
- No private keys
- No seed phrases
- No backend

## 🧱 Tech Stack

- HTML
- CSS
- JavaScript
- EVM JSON-RPC
- Blockscout API
- GitHub Pages

## 🔐 Security

This project only works with public wallet addresses.

It does not request:

- private keys
- seed phrases
- wallet signatures
- transaction permissions
- wallet connections

Never enter a private key or seed phrase into this website.
